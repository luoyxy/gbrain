# 论点 vs 事实 —— 架构区分

gbrain 有两个服务于不同目的的认识论存储层。
**永远不要混淆它们。**

## 论点（冷存储 —— `takes` 表）

认识论层。WHO 相信 WHAT，带有置信度权重和时间。

- **来源：** 通过 LLM 分析从大脑页面（markdown）提取
- **范围：** 多持有者 —— 捕获*任何*发言者的信念，不仅仅是大脑拥有者
- **种类：** `take` (意见)、`fact` (可验证)、`bet` (预测)、`hunch` (直觉)
- **生命周期：** 冷存储，回顾性。在页面更改或重新提取运行时更新。
- **规模：** 成熟大脑中跨数千个持有者的 100K+ 行。

**论点示例：**
- `holder=people/garry-tan kind=bet` "AI 将在 2030 年取代 50% 的编码" (w=0.75)
- `holder=people/jared-friedman kind=take` "Momo 有强大的留存率" (w=0.80)
- `holder=world kind=fact` "Clipboard 筹集了 $100M C 轮" (w=1.0)
- `holder=brain kind=hunch` "Garry 有一个英雄/救援者模式" (w=0.70)

**查询表面：** `gbrain takes list`、`gbrain takes search`、`gbrain think`

## 事实（热内存 —— `facts` 表，v0.31）

来自大脑拥有者对话的个人知识。实时捕获。

- **来源：** 通过事实钩子（Haiku）在每次轮换时从对话中按轮换提取
- **范围：** 单用户 —— 仅大脑拥有者的陈述知识
- **种类：** `event`、`preference`、`commitment`、`belief`、`fact`
- **生命周期：** 热存储，实时。在对话发生时捕获。
- **桥接：** 梦境循环 `consolidate` 阶段每晚将热事实 → 冷论点

**事实示例：**
- `kind=event` "我明天与 Brian 有会议"
- `kind=preference` "我不喝咖啡"
- `kind=commitment` "我们决定了嵌套托管"
- `kind=belief` "我认为市场过热了"

**查询表面：** `gbrain recall`、MCP `_meta.brain_hot_memory`

## 类别错误

**永远不要将论点转储到事实表中。** 论点包括其他人的归属
信念（Jared 对公司的评估、PG 对学校的看法、创始人的
 venue 声明）。这些*不是*大脑拥有者的个人事实。

**永远不要在没有转换的情况下将事实转储到论点表中。** 事实
范围限于拥有者在对话中说的内容。它们仅通过
梦境循环的 consolidate 阶段成为论点，后者添加适当的归属、去重和
时间推理。

## 桥接

梦境循环的 `consolidate` 阶段（v0.31）是单向桥接：

```
热事实 → [梦境 consolidate] → 冷论点
```

事实流向一个方向。consolidate 阶段：
1. 按实体分组相关事实
2. 与现有论点去重
3. 将持久事实提升为带有适当 holder/weight 的论点
4. 用 `consolidated_at` + `consolidated_into` 标记已合并的事实

## 生产提取数据（2026-05-10）

在 ~100K 页面的大脑上首次完整论点提取运行：
- **模型：** Azure GPT-5.5（以 1/8 的成本 tied Opus 质量 —— $0.033 vs $0.260/页面）
- **结果：** 来自 28,256 个磁盘页面的 100,720 个论点，$361.49，83 个错误（0.3%）
- **细分：** 70,960 个论点 / 24,342 个事实 / 2,875 个 bets / 2,649 个 hunches
- **持有者：** 6,239 个唯一持有者
- **跨模态评估：** 6.8/10 总（GPT-5.5 + Opus 4.6 独立评分）

| 维度 | 分数 | 备注 |
|-----------|-------|-------|
| 准确性 | 7.5 | 声明忠实地代表来源 |
| 归属 | 6.5 | Holder/subject 混淆是 #1 问题 |
| 权重校准 | 7.0 | 范围使用良好，一些虚假精度 |
| 种类分类 | 6.5 | 偶尔 fact/take 错误分类 |
| 信号密度 | 6.5 | 一些琐碎的提取通过 |

### 提取提示的关键学习

1. **Holder ≠ subject。** "Garry 有一个英雄/救援者模式" → holder=brain，而不是 people/garry-tan
2. **原子声明。** 将复合声明拆分为单独的行
3. **放大 ≠ 认可。** 仅限转推 → 最大权重 0.55
4. **自我报告 ≠ 已验证。** "报告 7 个数字" → holder=person，weight=0.75，而不是 world/1.0
5. **无虚假精度。** 使用 0.05 增量（0.35、0.55、0.75），而不是 0.74 或 0.82
6. **"那又怎样"测试。** 跳过 Twitter 句柄、关注者计数、明显的元数据
