# 每日任务管理器

## 合约

此技能保证：

- 任务存储为具有结构化格式的大脑页面（`ops/tasks.md`）
- 任务生命周期：添加 → 进行中 → 完成 | 推迟
- 优先级：P0（紧急）、P1（今天）、P2（本周）、P3（积压）
- 已完成的任务通过完成日期存档
- 推迟的任务带着原因向前推进

## 阶段

1. **加载当前任务。** `gbrain get ops/tasks` — 读取任务列表。
2. **执行请求的操作：**
   - **添加：** 附加带有优先级、描述、截止日期的任务。添加时间线条目。
   - **完成：** 标记为完成，通过日期移动到已完成部分。
   - **推迟：** 带着原因移动到下一天/周。
   - **移除：** 从列表中删除（罕见，首选完成或推迟）。
   - **审查：** 按优先级显示所有活跃任务。
3. **保存。** `gbrain put ops/tasks` — 写入更新的任务列表。

## 输出格式

```markdown
# 任务

## P0 — 紧急
- [ ] {任务描述}（截止日期：{日期}）

## P1 — 今天
- [ ] {任务描述}

## P2 — 本周
- [ ] {任务描述}

## P3 — 积压
- [ ] {任务描述}

## 已完成
- [x] {任务}（完成日期：{日期}）
```

## 反模式

- 添加没有优先级级别的任务
- 完成任务而不记录完成日期
- 推迟任务而没有原因
- 让任务列表无限制地增长（每周审查）
- 在大脑外存储任务（它们应该是可搜索的）
