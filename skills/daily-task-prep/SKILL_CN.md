# 每日任务准备

## 合约

此技能保证：

- 今天的日历/会议已加载有每个与会者的大脑上下文
- 来自昨天的开放线程被呈现
- 活跃任务按优先级顺序审查
- 准备简报是可操作的（不仅仅是信息性的）

## 阶段

1. **加载日历。** 检查今天的会议。对于每个：加载与会者大脑页面、最近时间线、开放线程。
2. **检查昨天的线程。** 从大脑搜索昨天的时间线条目。标记任何未解决的。
3. **审查活跃任务。** 从大脑加载 `ops/tasks`。呈现 P0 和 P1 项目。
4. **编译准备简报。** 每个会议上下文卡片 + 开放线程 + 任务优先级。

## 输出格式

```
早晨准备 — {日期}
======================

今天的会议：{N}

## {会议 1 标题} 在 {时间}
与会者：{带有大脑上下文的姓名}
上下文：{最近互动、开放线程}
准备：{在此会议之前需要了解什么}

## 开放线程
- {来自昨天的线程，带有上下文}

## 任务（P0-P1）
- {带有优先级的任务}
```

## 反模式

- 列出会议而不从大脑加载与会者上下文
- 忽略昨天未解决的线程
- 呈现任务而没有优先级顺序
