# 信号检测器 — 环境Brain捕获

轻量级子代理，在每条入站消息上触发，以**同等优先级**捕获两件事：

1. **原始想法** — 用户的想法、观察、论文、框架
2. **实体提及** — 人物、公司、媒体引用

原始想法**至少**与实体提取一样有价值。想法是智力资本。实体是簿记。两者都随时间复合。

## 契约

本技能保证：
- 在每条消息上触发（除非纯粹是操作性的，否则无例外）
- 并行运行（生成，永不阻塞主响应）
- 捕获带有用户**确切措辞**的想法（无释义）
- 检测实体提及并创建/丰富brain页面
- 记录捕获内容的一行摘要
- 反向链接所有实体提及（铁律）
- 写入的每个事实都有引用

> **约定：** 参见 `skills/conventions/quality.md` 了解铁律反向链接。

每次此技能创建或更新提及人物或公司的brain页面时：
1. 检查该人物/公司是否有brain页面
2. 如果有 → 从他们的页面**添加反向链接**到你刚刚创建/更新的页面
3. 格式：`- **YYYY-MM-DD** | 在 [页面标题](路径) 中引用 — 简要上下文`
4. 未链接的提及是损坏的brain。

## 阶段

### 阶段1：想法/观察检测（主要）

当用户表达新颖的想法、观察、论文或框架时：
- 如果是用户的**原始想法**（他们生成的） → 创建/更新 `originals/{slug}`
- 如果是他们引用的**世界概念** → 创建/更新 `concepts/{slug}`
- 如果是**产品或商业想法** → 创建/更新 `ideas/{slug}`

**捕获确切措辞。** 用户的语言**就是**洞察。不要释义。

**交叉链接（强制性）：** 每个原始内容**必须**链接到相关人物、公司、会议和概念。没有交叉链接的原始内容是死的原始内容。

### 阶段2：实体检测（次要）

1. 提取实体提及（人物、公司、媒体标题）
2. 对于每个实体：
   - `gbrain search "name"` — 页面是否存在？
   - 如果**没有**页面 → 检查显著性。如果显著，创建带丰富内容的页面。
   - 如果页面存在但**单薄** → 触发丰富
   - 如果页面存在且**丰富** → 无操作
3. 对于带特定日期的**新事实** → 调用 `gbrain timeline-add <slug> <date> "<摘要>"`

**自动链接（v0.10.1）：** 当你写入/更新引用人物或公司的originals或ideas页面时，`put_page`上的自动链接post-hook自动创建从新页面到该实体的链接。你不需要手动调用`gbrain link`。时间线条目仍需要显式调用。

### 阶段3：信号日志

始终记录一行摘要：
- `信号：0个想法，0个实体，0个事实（跳过：操作性的）`
- `信号：1个想法（已捕获 → originals/x），2个实体（已丰富 → people/y, companies/z）`

这使环境捕获循环可调试。

## 输出格式

不对用户显示输出。此技能在后台静默运行。
输出是创建/更新的brain页面和信号日志行。

## 反模式

- 阻塞主响应以等待信号检测完成
- 释义用户的原始想法而不是捕获确切措辞
- 为非显著实体（一次性提及）创建页面
- 创建/更新页面后跳过反向链接
- 在纯粹的操作性消息上运行（"ok"、"thanks"、"do it"）

## 使用的工具

- `search` — 检查实体页面是否存在
- `query` — 语义搜索相关上下文
- `get_page` — 加载现有实体页面
- `put_page` — 创建/更新brain页面
- `add_link` — 交叉引用实体
- `add_timeline_entry` — 在实体时间线上记录事件
